এই প্যানেলটি শুধু অ্যাডমিনের জন্য। API token শুধু এই ট্যাবের মেমোরিতে থাকবে; ব্রাউজারে সংরক্ষণ করা হবে না। কখনো token কাউকে পাঠাবেন না।

কমপক্ষে ৩২ অক্ষরের random secret। তৈরি token GitHub Actions Secret WORKER_ADMIN_API_TOKEN হিসেবেও যোগ করতে হবে।

সতর্কতা: কপিরাইটযুক্ত বইয়ের অনুমতি ছাড়া PDF প্রকাশ করবেন না। GitHub Release-এর PDF public হবে।

প্রথমে token দিন। এরপর GitHub Release-এ PDF আপলোড করে তার URL এখানে দিন।
নিবন্ধনের পর PDF index করার ধাপ
  1. GitHub repository → Releases → New release খুলুন।
  2. অনুমতিপ্রাপ্ত PDF ফাইল attach করে release publish করুন।
  3. উপরের ফর্মে release asset URL দিয়ে বই register করুন।
  4. GitHub → Actions → “Index PDF into D1” → Run workflow।
  5. বইয়ের ID এবং একই PDF URL দিন। Workflow সফল হলে বই ready হবে।
